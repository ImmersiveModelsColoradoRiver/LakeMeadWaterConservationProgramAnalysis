# R-Code: Lake Mead Water Conservation Program Analysis (Intentionally Created Surplus; ICS)
## Successes, Challenges, and Potential Improvements post 2026

This folder generates five plots to support the Lake Mead Water Conservation Program Analysis. Within the Colorado River basin, the Lake Mead water conservation program is called Intentionally Created Surplus (ICS) program for Lake Mead. This program is defined in the 2007 Interim Guidelines and 2019 Drought Contingency Plans (Reclamation, 2007; 2019).

Figure 1. - Water Conservation Account balances over time.
Figure 2. - Water Conservation Account deposits and debits over time.
Figure 3. - Lake Mead storage and storage estimated if the water conservation program did not exist.
Figure 4. - Conceptual models showing when the assumption that Physically Available Water (QPhysical) exceeds Total Legal Entitlements minus Total Mandatory Shortages (ETotal – MTotal) is valid (Case 1, left) or invalid (Case 2, right). In Case #2, there is a gap between Total Legal Entitlements and the Physical Available Water that the Total Shortage does not fill.
Figure 5. - Lake Mead inflow, evaporation, available water, and program deposits for which their was sufficient available water.

It also includes the Tables for the manuscript
**Tables-LakeMeadConservationProgram.xlsx**

Note - Available Water = Inflow - Evaporation.

## Requirements to Run

* R version 4.1.1. Download from https://cran.r-project.org/.
* R Studio 1.1.456. Download from https://www.rstudio.com/.

## Directions to Generate Results

**Figures 1 to 3:**

1. Download and install R and RStudio (see requirements)
1. Within this subfolder, open the **LakeMeadWaterConservationProgramAnalysis.Rproject** file. R Studio should open.
1. Select the **LakeMeadStorageICS.Rmd** tab (R markdown file) within R Studio.
1. Just below the tab, click the **Knit** button.
1. The code will run and generate the file **LakeMeadStorageICS.pdf**. Open the pdf file to view results.

**Figure 4:** Open the Powerpoint file **FixAnnualCredits.pptx**.

**Figure 5:***

1. Select the **LakeMeadInflow.Rmd** tab (R markdown file) within R Studio.
1. Just below the tab, click the **Knit** button.
1. The code will run and generate the file **LakeMeadInflow.pdf**. Open the pdf file to view results.

**Tables 2 and A1:** Open the Excel file **Tables-LakeMeadConservationProgram.xlsx**.

## Explanation of File Contents

1. **LakeMeadStorageICS.pdf** - PDF file with description of methods and Plots #1 to 3. Generated by the **LakeMeadStorageICS.Rmd** file.
1. **LakeMeadStorageICS.R** - R file with script to generate results in the R studio console. This file also has a bunch of other plots that show Lake Mead inflow using different methods.
1. **LakeMeadStorageICS.Rmd** - R mark down file with script to generate results in **LakeMeadStorageICS.pdf** file.
1. **LakeMeadInflow.pdf** - PDF file with description of methods and Plot#4. Generated by the **LakeMeadInflow.Rmd** file.
1. **LakeMeadInflow.R** - R file with script to generate results in the R studio console. This file also has a bunch of other plots that show Lake Mead inflow using different methods.
1. **LakeMeadInflow.Rmd** - R mark down file with script to generate results in **LakeMeadInflow.pdf** file.
1. **FixAnnualCredits.pptx** - Editable version of Figure 5 to fix credit accounting.
1. **Tables-LakeMeadConservationProgram.xlsx** - Excel file with calculations that generate Tables 2 and A1.

## Explanatio of Folder Contents

1. **R-Fig1to5\AutoReadUSBRData** - R functions to retrieve reservoir storage and elevation data from Reclamation's web portal. See further information in the **README.md** file within that folder.
1. **R-Fig1to5\EvapData** - Evaporation data for Lake Powell and Lake Mead in csv format.

## Additional Notes

Files **LakeMeadStorageICS.Rmd** and **LakeMeadInflow.Rmd** are currently configured to retrieve cached Reclamation reservoir storage/elevation data in the folder **AutoReadUSBRData** when the script was run in August 2026.
If you wish to download the most recent data from Reclamation's webserver:

1. Within the **LakeMeadStorageICS.Rmd** file, uncomment Line 69 and comment Line 70 (add a #).
1. Within the **LakeMeadInflow.Rmd** file, uncomment Line 101 and comment Line 102 (add a #).

For more information about these data retrieval functions, see the **README.md** file within the subfolder **R-Fig1to5\AutoReadUSBRData**.
